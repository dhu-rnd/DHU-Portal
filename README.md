# DHU Portal

このプロジェクトは、デジタルハリウッド大学の非公式ポータルです。  
学内情報の一元化と、学生の利便性向上を目標として開発されています。

## 免責事項

このプロジェクトは学生有志により開発された **非公式ツール** です。  
デジタルハリウッド大学、およびその関連機関とは一切関係がなく、公式な承認・支援・運営・管理を受けていません。
